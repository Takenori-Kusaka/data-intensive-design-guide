# 見た目の点検の担当への指示

デッキの各スライドは `deck/qa/sNNN.png`（1600×900）に書き出してある。スライド番号と Part ファイルの対応、各スライドの題は `deck/qa/slidemap.txt`。機械検査の結果は `deck/qa/overflow.txt`（「S129 over 5pt」＝そのスライドの箱から文字が 5pt はみ出し。「box 22」で文字がスライド番号だけの行は道具側で修正済みなので無視）。

担当の範囲の PNG を **1 枚ずつ全部** Read で見て、次を直す。直すのは `deck/pNN.js` の配置と文の長さだけ。**事実・数字・出典・主張の中身は変えない**（縮めるときも意味を変えない。削るなら修飾語や重複から）。

見るもの：
1. overflow.txt に載っている自分の範囲の件（箱を広げる、文字を小さくする（最小 10.5）、文を縮める）
2. リード（題の下の青い 1 文）が 2 行に折り返している → 1 行（全角 46 字以内）に縮める。折り返したリードは下の表や図に重なる
3. 根拠の行（下部の「仕様・文書／指針・報告／書籍」）が 3 行以上、または極端に小さい → 各項目を全角 60 字程度までに縮める（版と確認月、書籍のページは残す。複数の出典は主要な 2〜3 個に絞り、残りは発表者ノートの末尾に「出典の補足：…」として移す）
4. 表・カード・注記どうしの重なり、スライド下端（根拠の行、y 6.62）への食い込み、箱の中の文字のはみ出し、箱の中の大きな空白（箱を縮めるか配置を整える）
5. 行頭に「。」「、」「）」が来ている折り返し、1 文字だけの行 → 文を数文字縮めるか列幅を調整
6. 表の列幅が偏って片方だけ何行にも折り返している → colW を調整（合計は w と同じに）
7. 図（L.box・L.arrow・L.flow）の矢印が箱とずれている、ラベルが箱からはみ出している
8. 題が 2 行になっている → 34 字以内に

PowerPoint は起動しない（再書き出しは取りまとめ役が行う）。直したら `cd deck && export NODE_PATH="<pptxgenjs などを入れた node_modules のパス>" && node build_one.js pNN` でエラーなし・refs 漏れ 0・ノート漏れ 0 を確かめる。配置は AUTHORING.md 3 節の数値（本文 x 0.6〜12.7、y は 6.5 まで、14pt は 1 行およそ「幅(インチ)×5 字」、行の高さ 0.3 インチ、表は rowH × 行数）で計算する。
